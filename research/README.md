# research/ — the evidence base

One sources file per unit: `unitNN-<slug>-sources.md`. Written by the agent during `create chapter`.

Each holds the URLs used, key quotes/snippets, and a **one-line authority note** per source. This
makes every reading auditable (trace any claim back here) and keeps re-runs from starting cold.

A reading with no citation back to a source here is a bug. See research rules in
[`../CLAUDE.md`](../CLAUDE.md).
